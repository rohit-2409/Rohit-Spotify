# Spotify Web Player Clone

A fully responsive, pixel-perfect frontend clone of the Spotify Web Player. This project replicates the core user interface of Spotify and implements active audio playback controls using native JavaScript.

## 🚀 Live Demo
https://spotifyclone3y4y3.netlify.app/

## ✨ Features

* **Authentic Spotify UI:** Built with Spotify's signature dark theme, sidebar navigation, card layouts, and bottom media player controller.
* **Interactive Audio Player:** Play, pause, skip tracks, and adjust audio playback dynamically.
* **Dynamic Progress Bar:** The seek bar updates in real-time as songs play and allows users to skip to different parts of a track.
* **Tailwind Utility Design:** Fully responsive grid systems and hover states mimicking the exact desktop and mobile behavior of Spotify.
* **Song Library:** Built-in curated array of songs with corresponding cover art, track titles, and artist data.

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling:** Tailwind CSS (via CDN / PostCSS setup)
* **Interactivity & Audio Logic:** Vanilla JavaScript (HTML5 Audio API)
